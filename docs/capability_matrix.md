## How to read this

Support is recorded per coin, operation and variant (PRD §13.1). A variant is a concrete transaction or message shape; one passing vector proves one variant, not a chain.

- **generated** — the coin's protobuf (or the T2.9 probe evidence) defines the operation and the registry lists the coin. Produced mechanically; says nothing about the SDK.
- **exposed, unverified** — the public SDK offers a typed or generic path, and no vector for this exact variant is confirmed on both Android and iOS.
- **tested** — a known-answer vector for this exact variant lists both `android` and `ios` in `platforms_verified`, and `matrix:check` confirms it against the CI results.
- **conflict** — the evidence sources disagree; reported, not resolved.
- **—** — not generated for the coin.
