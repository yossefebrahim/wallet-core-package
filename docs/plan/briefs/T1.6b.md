  2. `lib/src/memory/leak_tracker.dart` — `final class LeakTracker implements ResourceObserver` (item 7):
     - Records, per `onResourceCreated`: an id, the `runtimeType` name, `StackTrace.current` (the allocation site — TM-11), and a `WeakReference` to the resource.      - Detects **finalized without dispose** with a managed `Finalizer` (`dart:core`, *not* `NativeFinalizer`) attached to each resource with the record id as its token: when the resource is collected and its record is not marked disposed, the leak count goes up and the record moves to the leaks list.
