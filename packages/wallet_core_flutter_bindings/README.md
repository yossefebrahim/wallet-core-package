# wallet_core_flutter_bindings

Unofficial Dart/Flutter SDK for the open-source Trust Wallet Core library. Not affiliated with or endorsed by Trust Wallet.

The generated bindings layer of the `wallet_core_flutter` workspace.

## Status

pre-release; no published artifact set yet — see the root README

## Entry points

- `ffi/`, `proto/`, `registry/`: The generated code. These are never hand-edited.
- `memory/`: The memory wrappers. See the disposal contract pointer at `docs/security/memory_contract.md`.
